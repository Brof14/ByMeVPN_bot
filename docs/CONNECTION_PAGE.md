# Страница подключения ByMeVPN

`/connect` — небольшая HTTPS-страница, которую бот открывает вместо прямой
ссылки подписки. Она определяет ОС браузера, позволяет переключить её вручную,
показывает доступный клиент и предлагает скачать его или скопировать ссылку для
другого приложения.

## Production

- Публичная точка: `https://bymevpn.duckdns.org:8443`.
- В `vpnbot` отдельный TLS listener отдаёт только `/connect`, `/app/login` и
  `/healthz`; остальные API и webhook-маршруты через этот listener не
  публикуются.
- Сертификат и закрытый TLS-ключ подключаются контейнеру только для чтения.
- `APP_PUBLIC_URL` и `APP_CONNECT_PAGE_URL` задаются для обоих экземпляров
  бота. TLS listener запускается только основным экземпляром.
- Для действующей подписки Telegram выдаёт **постоянную персональную ссылку**
  `/connect?u=…&k=…&s=…`: она подписана, привязана к выбранному ключу и не
  содержит адрес подписки или UUID. Подпись использует случайную индивидуальную
  эпоху из SQLite (`connect_link_epochs`) и серверный секрет.
- Всякий успешный перевыпуск VPN-конфигурации **атомарно меняет эпоху ссылки**
  вместе с учётными данными. Это отзывает ранее скопированные URL, даже если
  строка адреса подписки случайно совпадёт. Старые ссылки формата v2 доступны
  только до первого успешного перевыпуска после обновления.
- Зашифрованный `ticket` — отдельный сценарий передачи конфигурации, не
  персональная постоянная ссылка. Страницы и сообщения об ошибках не кэшируются;
  Uvicorn access-логи отключены.
- Перед публикацией новых ссылок запустить миграцию `init_db()` для
  существующей SQLite. Резервная копия должна включать новую таблицу.

## Клиенты

Страница рекомендует Happ для Android, Windows и Linux. Приложения ByMeVPN для этих платформ находятся в разработке. Для
другого клиента пользователь копирует ссылку подписки и импортирует её вручную.
Переходы в приложение и доступность страницы требуется отдельно проверить на
реальных Android, iOS и desktop-устройствах: успешный HTTPS-ответ сам по себе не
подтверждает, что конкретный клиент обработал deep link.

## Telegram Premium emoji

Bot API сейчас сообщает, что оба экземпляра не могут отправлять premium emoji
как иконки кнопок. В тарифах остаётся один обычный `🎁` на предложение с
подарочными месяцами. После предоставления ботам соответствующей возможности
можно включить `BOT_PREMIUM_BUTTON_ICONS=1`; проверяйте каждую иконку через
Telegram перед распространением.

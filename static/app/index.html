Первая установка

  1. Скачайте APK по кнопке выше, когда появится опубликованная версия.
  2. Откройте файл и разрешите установку приложений для браузера, если Android попросит об этом.
  3. После установки откройте ByMeVPN и войдите по электронной почте.

Требуется Android 7.0 или новее. Для установки обновлений Android может снова запросить подтверждение.
